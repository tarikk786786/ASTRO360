# ASTRO360 — Landing Page Design System

## 1. Palette & Surface Hierarchy
- **Canvas Base**: `#090A0C` (Matte Obsidian)
- **Primary Surface**: `#111315` (Deep Slate Card)
- **Elevated Surface**: `#181A1D` (Interactive Card Hover)
- **Subtle Surface**: `rgba(255, 255, 255, 0.03)`
- **Borders**: `rgba(255, 255, 255, 0.08)` / Active: `rgba(255, 255, 255, 0.20)`

## 2. Astrological Harmonic Accents
- **Solar Amber (Surya)**: `#F59E0B`
- **Mercury Emerald (Budha)**: `#10B981`
- **Jupiter Gold (Guru)**: `#EAB308`
- **Celestial Sky Blue (Akasha)**: `#38BDF8`
- **Venus Rose (Shukra)**: `#EC4899`
- **Saturn Slate (Shani)**: `#94A3B8`

## 3. Typography Tokens
- **Display**: Sans-serif, tracking-tight, font-black (36px - 64px)
- **Heading**: Sans-serif, tracking-tight, font-bold (20px - 32px)
- **Body**: Sans-serif, text-slate-300, leading-relaxed (14px - 16px)
- **Technical / Telemetry**: Font-mono, uppercase, font-bold (11px - 13px)

## 4. Touch & Ergonomics
- Minimum touch target: `48px x 48px`
- Safe area insets: `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`
