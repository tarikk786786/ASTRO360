# ASTRO360 — Free-First Unlimited AI Architecture

## 1. Core Mission & Philosophy
ASTRO360 delivers a self-hosted, open-model, privacy-first personal astrology AI assistant with **ZERO mandatory paid commercial LLM APIs**.

- **ASTROCORE**: Calculates 100% of celestial ephemeris and coordinates deterministically.
- **Rules Engine**: Encodes classical scripture rules (*BPHS*, *Tetrabiblos*, *KP Readers*).
- **Multi-Engine Consensus**: Computes cross-system directional concordance.
- **Hybrid RAG**: Ingests verified domain literature using local BGE-M3 multilingual embeddings.
- **Local LLM**: Formulates explanations, synthesizes evidence, and provides practical reflection using open weights via `llama.cpp`.
